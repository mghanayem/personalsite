## Part 3 — Admin panel (full CMS control)

### Access and security
- Admin panel at `/admin`, protected by session auth. All `/admin` routes require login.
- Seed the database with a default admin account: username `Admin`, password `admin`. The password must still be stored hashed with bcrypt, never in plain text.
- After the first login with the default password, show a clear banner prompting the admin to change it.
- Include an **Account Settings** page where the admin can change both the username and the password (require current password to confirm).
- Secure httpOnly session cookies, logout button, and basic rate limiting on the login route.

### Section-based content model (the core of the CMS)
Every page on the site, including the homepage, is built from an ordered list of **sections**. The admin has full control:

- **Add a section** to any page, choosing a section type:
  - Text (title + rich text)
  - Text with image (image left or right)
  - Image gallery (one or more images with captions)
  - Cards grid (repeating items with icon/title/description, used for Skills, Strengths, Services)
  - Timeline (repeating entries with heading, subheading, date field, and bullet list, used for Experience)
  - Contact strip
- **Edit any section**: every text field has side-by-side Arabic and English inputs; rich text via a lightweight editor (Quill or a markdown editor with preview)
- **Reorder sections** with up/down controls or drag-and-drop
- **Remove any section** (with a confirmation dialog)
- **Images per section**: upload images (jpg, png, webp) into any section that supports them, replace an image, or remove an image. Validate file type and size (max 5 MB). Store files in `/public/uploads` and clean up files when an image is removed.
- **Show/hide a section** without deleting it (visibility toggle)

### Pages manager
- Create, edit, publish/unpublish, and delete pages
- Each page has: title (AR + EN), URL slug, ordered sections (as above), published status, and a "show in navigation" toggle
- Published pages are served at `/p/:slug` (Arabic) and `/en/p/:slug` (English) using the site's design
- The homepage appears in the pages manager as a special, non-deletable page so its sections can be edited the same way

### Dashboard home
- Overview: number of pages, published vs draft, quick link to create a new page

### Database schema (SQLite)
- `users`: id, username, password_hash
- `pages`: id, title_ar, title_en, slug (unique), is_published, show_in_nav, is_homepage, created_at, updated_at
- `sections`: id, page_id, type, sort_order, is_visible, data (JSON holding all AR/EN fields and image references)
- `images`: id, section_id, filename, caption_ar, caption_en, sort_order
- Seed on first run with the homepage sections and content from Part 2, plus the default admin user
